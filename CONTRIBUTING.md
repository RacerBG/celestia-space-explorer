# Contributing to CSE

Thank you for your interest in contributing to Celestia Space Explorer (CSE)!

Contributions, bug reports, suggestions, and improvements are always welcome.

## Reporting Bugs

If you encounter a bug, please open an issue using the Bug Report template.

Include as much relevant information as possible, such as:
- Operating System
- CSE Version
- Celestia Version
- Steps to reproduce the issue
- Relevant error messages, if available

## Suggesting Features

Feature requests and suggestions are welcome. Please open an issue using the Feature Request template to describe your idea.

## Pull Requests

If you would like to contribute code:

1. Fork the repository.
2. Create a branch for your changes.
3. Make your changes.
4. Test them in Celestia.
5. Submit a Pull Request using the Pull Request template and include a clear description of your changes.

Please keep contributions focused and consistent with the existing code and project structure.

## Development

CSE is written in Lua and uses Celestia's CELX scripting API.

Contributions should remain compatible with the supported Celestia environment.

## Questions

If you have questions about CSE or contributing, feel free to open an issue.

Thank you for helping improve CSE!
